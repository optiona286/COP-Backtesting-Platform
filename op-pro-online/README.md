# OP PRO Online

## 線上版與 R2

GitHub 只保存這個独立線上版的程式和介面資源。`data/`、憑證、上傳進度、暫存檔不進 Git；行情壓縮檔與 `online-index.json` 保存於 Cloudflare R2。

發佈版的 `js/config.js` 以 `dataBaseUrl` 指向 R2 公開網址。瀏覽器按日期讀取 gzip，保留五分 K 的 OHLC，可聚合成更長週期。報價、播放與回測依五分 K 完成時間更新，無法還原逐筆路徑或區間內觸價順序。

網站可由靜態主機提供，不需要原版的本機行情 API。GitHub 儲存程式與部署網站是兩個步驟；部署時的網站 origin 必須加入 R2 CORS。上傳程式不會自動設定 GitHub Pages。

以下早期設計與後端描述為沿革紀錄；目前資料模式以上述 R2 方案為準。原版資料夾不包含在此次線上版變更內。

從 OP PRO 根目錄目前使用的版本複製而來的獨立 RWD 版本。原版、op_pro、backups 與 op-pro-v2 保持原位；此資料夾可以獨立交由 GitHub 管理。

## 啟動

安裝 Node.js 22 或更新版本後，雙擊 `Start_OP_PRO_Online.vbs`，或在此資料夾執行 `npm start`。不需安裝 npm 套件。

網址：http://localhost:5100。原版使用 5000；新版啟動器不停止原版，也不強制終止其他程序。若新版服務已啟動，啟動器直接開啟它；修改後端後請停止新版服務再重新啟動。

## 改動範圍

目前介面已改為手機優先的 App 風格；寬螢幕也呈現置中的手機工作區。以下三區交易終端是前一階段的設計，已由手機工作區切換取代。

- 底部圖表／報價／交易／帳戶／設定，切頁有短轉場，頁面保存各自捲動位置。
- 頁面標題區支援左右滑動切頁；圖表內的手勢保留給圖表本身。
- 右上「下單」或交易頁的「開啟下單面板」開啟底部面板。拖曳把手、點關閉、按 Escape 或點遮罩可收起，輸入值保持原樣。
- 回測先顯示播放按鈕與進度；「播放設定」展開速度、步進與跳轉等原有控制。
- 保留深淺主題、完整原有功能與交易狀態；支援安全區及減少動態效果偏好。
- 新增 css/mobile-app.css、js/mobile-app.js，只負責呈現與互動。這是瀏覽器版 App 介面，尚未封裝原生安裝包或新增 PWA 離線功能。

### 前階段交易終端

- 桌面採用緊湊三區交易終端：左側 T 字報價、中間圖表、右側市價／限價下單與風控。區域之間可拖曳調整寬度，也支援鍵盤方向鍵。
- 主要商品、週期與時段放頂列，其餘設定由右上「設定」展開。
- 回測控制列移到主畫面下方；部位、委託、成交、帳戶與條件策略使用底部分頁。
- 平板與手機使用底部「圖表／報價／交易／帳戶／設定」切換。結算日、契約、週期及時段等控制項集中到設定頁，其他主頁不再顯示頂部選單。所有區域共用原有商品與回測狀態，切換不建立新交易帳戶。
- 表格在自己的區塊內捲動；T 字報價保留完整 CALL/PUT 欄位。
- 保留原有所有 DOM ID、腳本順序與交易控制項。沒有重寫回測、委託撮合、損益、風控及自動下單計算。
- 新增 `css/workspace.css`、`js/workspace.js`；原有樣式與其餘模組保持複製時內容。
- `js/backend.js` 與 `js/main.js` 僅調整 API 位址；`server.js` 改預設埠、服務識別、可跳過啟動結算價刷新及靜態檔案存取範圍。
- favicon 引用大小寫修正，方便將來在區分大小寫的環境運行。

## 行情資料

沿用原版的環境變數及預設資料庫路徑。大型行情資料庫未複製進此專案：

| 環境變數 | 預設 |
| --- | --- |
| `OP_PRO_DATA_DIR` | `D:\op_pro\data` |
| `OP_PRO_TAIEX_DIR` | `F:\加權指數5s\加權指數資料庫` |
| `OP_PRO_TX_DIR` | `F:\加權指數5s\台指期資料庫` |
| `PORT` | `5100` |

`fsp_data.csv` 是專案內獨立副本；原版檔案不會被此服務更新。
需要自訂設定時，複製 `.env.example` 為 `.env` 並執行 `node --env-file=.env server.js`。VBS 不自動載入 `.env`。
設置 `OP_PRO_SKIP_FSP_REFRESH=1` 可在啟動時使用本地結算價副本。行情檔案的掃描、資料解析及交易 API 維持原有流程。

## GitHub 與部署

此階段只建立本機版本，沒有建立遠端倉庫、推送或部署。
可以將整個 `op-pro-online` 資料夾上傳到一個新的 GitHub 倉庫，請不要附帶舊版父目錄或行情資料庫。

目前完整功能的建議運行方式為本專案 Node 後端與前端一起運行。GitHub Pages 只能提供靜態介面；行情 API 仍需另外部署。
將來若使用獨立的 HTTPS API，在 `js/config.js` 設定 `apiBase`，後端需要相應的 CORS 設定。現階段伺服器綁定 127.0.0.1；雲端部署前須另行配置公開監聽、資料庫、HTTPS 與存取權限。
外部圖表函式庫仍沿用原版 CDN，首次載入需要網路。此版没有加入假行情或替代交易邏輯。

## 驗證

- `npm run check`：檢查原有控制項、脚本順序、原封不動的邏輯及資源檔、API 調整後的模組雜湊及 JS 語法。
- `npm run check:original`：額外比對父目錄原版檔案是否保持建立新版前的雜湊。將資料夾獨立移出後，請使用一般 check。
- `docs/original-baseline.json`：原版來源的相對路徑與 SHA256。
- `docs/interface-contract.json`：原有控制項與模組順序。

瀏覽器驗證紀錄請見 `docs/verification.md`。

本次交易終端重排依使用者要求未執行自動測試，視覺及操作驗收由使用者進行。刷新已開啟的新版頁面即可載入新介面，後端沒有因這次改版變動。
